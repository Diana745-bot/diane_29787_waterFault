# Project Dataset

## Dataset Name
Water For People_Rwanda_2021

## Data Source
Water Point Data Exchange (WPdx) Catalogue.

Dataset link: https://catalog.waterpointdata.org/datasets/wfp-rwanda-621f8339/index.html

## Description
This dataset contains information about public water points in Rwanda. It includes geographical locations, water-point technology, functionality and other service-related information.

## Dataset Usage
The dataset will provide initial water-point information for the Public Water Fault Tracking System. It will help populate and organize records in the WATER_POINTS table.

## Project Data Limitation
The dataset does not provide a complete history of reported faults, inspections, repair assignments, maintenance activities or repair costs. These records will be managed separately by the project database.

## File Included
- `water_for_people_rwanda_2021.xlsx`

## Data Preparation Status
The original Excel dataset has been uploaded to this repository. Further inspection, cleaning and preparation will be carried out before importing the relevant records into Oracle Database 21c.
## Dataset Files

1. **water_for_people_rwanda_2021.xlsx** – The original dataset downloaded from Water For People.
2. **water_for_people_rwanda_2021_cleaned.xlsx** – The cleaned copy used for the project. One incomplete record was excluded, leaving 2,061 water-point records.

The original dataset is preserved for reference. The cleaned version is intended for data preparation and database import.
