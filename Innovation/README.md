# Innovation – Oracle APEX Interface

The planned innovation for the Public Water Fault Tracking System is a web-based interface developed using Oracle APEX and connected to the Oracle database.

The interface will help authorized users to:

- Register faults reported at public water points.
- View and manage fault reports.
- Record inspection results.
- Assign maintenance teams.
- Monitor repair progress.
- View maintenance history and costs.

PL/SQL will handle the database operations and business rules, while Oracle APEX will provide a user-friendly interface.

**Implementation status:** Planned. Development will begin after the database structure and core PL/SQL components are completed.
