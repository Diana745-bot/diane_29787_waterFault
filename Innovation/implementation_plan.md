# Innovation Implementation Plan

## 1. Proposed Technology

Oracle Application Express (APEX) will be used to develop a web-based interface connected to the Oracle Database 21c.

## 2. Main Interface Components

The planned interface will include:

- **Dashboard:** Display an overview of reported faults and repair activities.
- **Water Points:** View registered water points and their locations.
- **Fault Reporting:** Register new faults and their descriptions.
- **Inspections:** Record inspection findings.
- **Maintenance:** Assign teams and monitor repair activities.
- **Reports:** Review fault history, repair progress and maintenance costs.

## 3. Database Integration

Oracle APEX will connect to the project's Oracle database. The interface will use database tables and PL/SQL procedures and functions to manage information and enforce business rules.

## 4. Development Stages

1. Complete the database design.
2. Create and populate the database tables.
3. Develop the required PL/SQL procedures, functions, packages and triggers.
4. Configure the Oracle APEX application.
5. Connect the application pages to the database.
6. Test the main operations.
7. Document the completed application with screenshots.

## 5. Current Status

The innovation is still in the planning stage. Implementation and testing will take place after the core database and PL/SQL components are ready.
